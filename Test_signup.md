# Test Case 003: User Registration with Valid Details

## Test Objective
Verify that a new user can successfully register an account using valid personal details and a secure password.

## Pre-conditions
- User is on the registration/signup page.
- Email address is not already registered in the system.

## Test Steps
1. Enter a valid first and last name in the name fields.
2. Enter a unique, valid email address in the "Email" field.
3. Enter a secure password meeting complexity requirements in the "Password" field.
4. Confirm the password in the "Confirm Password" field.
5. Click the "Sign Up" or "Register" button.

## Expected Result
- Account is successfully created.
- User is redirected to the welcome onboarding screen or dashboard.
- A confirmation email is triggered to the user's inbox.
